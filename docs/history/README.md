# Project history

Long-form history that used to live in `CLAUDE.md`. It moved here on 2026-10-31
because `CLAUDE.md` loads into every session and had grown to ~6,400 lines
(about 95k tokens per session).

- `claude-md-archive-2026-10-31.md`: the full `CLAUDE.md` as it stood on `main`
  that day, unchanged. Every finished plan (Put-away, Duplicates, Voice,
  Expiring, Recipes v1/v2, Meal Plan, Deployment), every session note, and the
  reasoning behind past decisions. Old references like "see CLAUDE.md's Recipes
  plan" or `CLAUDE.md:4698` now point into this file (line numbers unchanged).
- `structure-rationale.md`: the provenance stories moved out of `STRUCTURE.md` on 2026-11-08 (why a rule exists, which mission added it, its corrections), word for word. Rules stay in `STRUCTURE.md`, which points here by heading.

Nothing here loads automatically. Read or search it when you need the story
behind a decision.
