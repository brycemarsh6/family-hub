Q2. Setup step 1: family name

Recommend: heading "Welcome to Marshee", one question "What's your family called?", hint text "The Smiths". Two dots show it's step 1 of 2. Required, up to 60 characters.

Q3. Setup step 2: your login

Recommend: "Your name" plus "Password" and "Password again". Two password boxes because there is no email reset, so a typo would lock them out. At least 8 characters, same rule as everywhere else. This person becomes the family's first admin. A "Back" link returns to step 1 without losing what they typed.

Q4. The recovery code, shown once

Recommend: 16 letters and numbers in four groups, with look-alike characters left out (no 0/O, 1/I/L), so it is easy to copy by hand. A "Copy" button, a warning that it won't be shown again, and a tick box "I saved my code" that must be ticked before Continue. Continue signs them straight in with the password they just made (no retyping) and opens the dashboard. PR 7 will point it at the welcome steps instead.

Q5. "Forgot password?" on the sign-in page

Recommend: a small "Forgot password?" link under the Sign in button, for every account. For an admin it opens the recovery view (recovery code, new password, new password again). For everyone else it shows "Ask an admin to set a new password for you in Settings, Manage family." because only admins can use the code. One code for the whole family, not one per admin.

Q6. Settings card for admins

Recommend: its own card titled "Recovery code", admins only, placed just under "Feedback". It shows whether a code exists ("Saved" or "No code yet") and a "Make a new code" button. The new code shows once on the same screen as Q4. No password check before making one: a signed-in admin can already reset anyone's password in Manage family, so asking again adds a step without protecting anything new. Your copy starts at "No code yet" because it was never set up through the link, so you'd make one there yourself.
